# 🛸 Rick and Morty Explorer

Web application built with **Next.js** that leverages the **Rick and Morty API** to browse, search, and view detailed profiles of characters from the show.

> 🛠️ **Project Status:** This is a **personal pet project** created to explore the power of Next.js, including its modern routing capabilities, server-side rendering, and API integration.

---

## 🚀 Live Demo

🔗 [View Live Project](https://react2025q3-wheat.vercel.app/rs-react-app/en)

---

## ✨ Features

- **Character Directory:** Responsive layout showcasing characters fetched directly from the Rick and Morty API.
- **Real-Time Search:** Filter and find your favorite characters by name with a search mechanism.
- **Detailed Profile Pages:** Deep-dive into character facts (status, species, gender, origin, and last known location) via dynamic detail views.
- **CSV Data Export:** Select multiple characters using checkboxes and seamlessly **download their information as a CSV file** directly to your device.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **State Management:** Redux Toolkit (used for managing character selection states cleanly across components)
- **API Integration:** Rick and Morty REST API (Fetch API)
- **Styling:** Standard CSS (Vanilla CSS files)
- **Routing:** Built-in Next.js Dynamic Routing

## 📦 Installation & Local Setup

Follow these steps to get the project running on your local machine:

1. **Clone the repository:**

   ```
   git clone https://github.com/violettab21/react2025q3.git
   ```

2. **Checkout to correct branch:**

   ```
   git checkout nextjs-ssr
   cd rs-react-app
   ```

3. **Install dependencies:**

   ```
   npm install
   ```

4. **Start the development server:**
   ```
   npm run "next dev"
   ```
   Open [http://localhost:3000/rs-react-app](http://localhost:3000/rs-react-app) with your browser to see the result.
